# Chatting Application 💬

A real-time desktop chatting application built using Java, Java Swing, and Socket Programming. The application follows a client-server architecture and enables instant messaging between connected users over TCP sockets with a simple and interactive Swing-based interface.

## 🚀 Features

* Real-time messaging between server and client.

* Client-server architecture using TCP sockets.

* Multithreading for simultaneous sending and receiving of messages.

* User-friendly desktop GUI built with Java Swing.

* Lightweight and easy-to-run Java application.

## 🛠️ Tech Stack

* Language: Java

* GUI: Java Swing

* Networking: Java Socket Programming (TCP)

* Concepts: Multithreading, OOP, Client-Server Architecture

## ⚙️ How to Run

### 1. Clone the Repository

Bash

```
git clone https://github.com/your-username/chatting-application.git
cd chatting-application
```

### 2. Compile the Project

Bash

```
javac src/*.java
```

### 3. Start the Server

Bash

```
java -cp src Server
```

### 4. Start the Client

Bash

```
java -cp src Client
```

Open multiple client instances to chat through the server.

## 📸 Application Workflow

1. Start the server.

2. Connect one or more clients.

3. Exchange messages in real time.

4. Messages are handled concurrently using separate threads for sending and receiving.
